# Binary Goldbach certificate at the upper endpoint

The pilot covers the 1,024 consecutive even targets from 9,999,999,999,997,954 to 10,000,000,000,000,000, inclusive. Its 19 prime anchors and 395 marked small primes use 484 shared recursive Lucas certificate nodes. The final target has the witness 2,063 + 9,999,999,999,997,937.

`python pilot.py` regenerates the certificate, checks it with integer arithmetic, and emits `UpperBinaryPilot.lean`. The generator searches for candidate primes, factors each candidate's predecessor and supplies a Lucas base. The checker reconstructs primality from those certificates, checks the shift of each anchor, and checks a pair of summands at every index. Its upper bound requires inclusion of the even target 10^16.

`python pilot.py --verify` replays the saved JSON in a fresh process. The recorded generation used 0.046875 CPU seconds. A second process verified the SHA-256 `7b4aff95dfd28779062468926596d591ad3534c1155104ee7c570fffb564733c` fixture in 0.03125 CPU seconds. The coarse Windows CPU clock limits the precision of these figures. Separate in-memory controls rejected a Lucas base of one, an empty coverage bitmap, and an interval shifted by two.

The generated Lean module supplies the concrete tree and witness list to the existing `BatchPrime.treeValid`, `BatchPrime.checkedCover_sound`, and `PrimeCoverage.binaryGoldbach_interval` declarations. Lean 4.35.0 compiled the resulting `UpperBinaryPilot.binary_interval` at trust level zero. It took 33.25 CPU seconds and 96.94 wall seconds including imports, compilation and the axiom check. Lean reported exactly `[propext, Classical.choice, Quot.sound]`. The first build caught a collision with Mathlib's `Tree`. The corrected generator uses qualified `BatchPrime.Tree` constructors. The saved JSON stayed unchanged.

`python check_lean.py <unused-run-name>` reproduces the one-process build and axiom audit using the local cached Lean dependencies. The successful run's exact command, dependency hashes, source hash, artifact hash, and process times are in `checks/endpoint02/receipt.json`. The theorem and axiom output are in `checks/endpoint02/lean.log`. A production run still needs representative wider blocks and a way to reuse the shared prime table across them.
