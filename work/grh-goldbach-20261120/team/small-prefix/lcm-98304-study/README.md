# Replacing the factorial anchor modulus through 100 million

For d=10000 the producer uses L=lcm(1,...,d), a 14,447-bit integer, in place of the 118,459-bit factorial. Lean checks that every positive integer through d divides the supplied L. In LcmBridge.support_coprime, an induction on k proves Coprime x (k!) for k<=d from Coprime x L, using coprimality with a divisor and with a product. Thus the original prime-test lemma consumes its original factorial coprimality premise. The source-prime bitmap checker is unaffected. The public bound remains inclusive and its declaration has the same type.

The exact-width control is ../width-98304-study. Both files use the same 509 rows, including widths, counts and all anchor offsets; only the anchor inverse field and its modulus/support proof change. Both axioms audits yield propext, Classical.choice and Quot.sound. Direct producer timing was 0.875 CPU seconds with a 20,140 KiB peak against 0.734375 and 19,964 KiB. The main LCM proof build took 39.859375 CPU seconds and peaked at 1,906,308 KiB against 46.0625 and 1,994,312 KiB. The private bridge cost 16.375 CPU seconds to compile once. The fresh LCM axiom audit cost 14.703125 CPU seconds. These individual timings were taken under varying host load.
