## A denser ladder with the cubic primality criterion

The selected checker uses `F = 2^45`. At `B = 10^16` even one original search window spans `2047F > B`. The cubic criterion permits `F = 2^30` because `2F³ = 2^91 > 10^27`. Take `S = 4654565`, and in window `i ≥ 1` seek a prime `c = RF + 1`, with `R = 2(Si − t) + 1`, `0 ≤ t ≤ 2047`. R is odd and coprime to F. The maximum difference between candidates in successive windows is `2(S + 2047)F = 9999998125080576 < B − 2`. The initial gap from 3 has the same bound. Let `K = ceil(10^27/(2FS)) = 100043997089`. Even the lowest candidate in the last window is above `10^27 − B`, since `2·2047F < B`. Even the highest is below `2^91`. For an increasing ladder of odd primes, rung `p` covers odd targets from `p + 4` through `p + B`. The gap bound makes these intervals contiguous on the odd integers. Start at 3. No conjecture about prime distribution enters this inference. [Published numerical ladder method](https://arxiv.org/abs/1305.3062)

For each accepted candidate, a modular calculation `a^((c−1)/2) = −1 mod c` supplies both BLS power conditions for the sole prime dividing F. Indeed the full power is 1 and the half power minus one is coprime to the odd number c. With `s = R div (2F)` and `r = R mod (2F)`, also check `s = 0` or that the integer `r²−8s` is not a square. Bridge both modular and square certificates into the existing general theorem `GoldbachLean.Saouter1998.BLS.lemma1`. The specialized original theorem for `F=2^22` cannot certify this schedule. The selected repository's batch checker, offset representation and construction are implementation references. It needs new exponent/index widths and an additional sound discriminant check. If a window has no accepted candidate, use other bases or other certified ordinary primes in the allowed subinterval and check the actual neighboring gaps. Existence of 2048 candidates alone gives no uniform success proof. [General theorem statement](https://github.com/sthubbar/goldbach-lean/blob/f003a97d7598923787920723668d62c16c82b81e/entries/saouter1998/GoldbachLean/Saouter1998/Lemma1.lean) [Proof](https://github.com/sthubbar/goldbach-lean/blob/f003a97d7598923787920723668d62c16c82b81e/entries/saouter1998/GoldbachLean/Saouter1998/Lemma1Proof.lean)

At an assumed 0.1, 1 or 10 ms of complete producer plus first-check CPU time per ordinary rung, the ladder alone consumes about 2,779, 27,790 or 277,900 core-hours. Each number comes from `K × seconds_per_rung / 3600`. The estimates exclude binary certification and extra infrastructure, retries, or extraordinary fallback beyond the assumed ordinary rate. A complete checked interior shard near 10²⁷ with a broken-certificate control would calibrate the rate. The current 2^45 wide Proth timing gives no measurement of the cubic criterion. A failed window rates as an exception even if adjacent windows happen to contain other usable primes.

## Dudek as a lower-compute option

Hubbard's standalone `entries/dudek2014` development supplies `theorem2_of_RH_hsw`. Its conclusion is a prime in `(x − (4/π)√x log x,x]` for every real x ≥ 2. The remaining input alongside Mathlib `RiemannHypothesis` is `HSWN70 gZ`. This includes both a bound on the number of zeros with `|Im ρ| ≤ T` and a shell bound for `T < |Im ρ| ≤ t`, with multiplicity, for every `70 ≤ T ≤ t`. Full RH only locates these zeros. The current public inventory at `93b86c0` still records this explicit hypothesis. Its added finite prime-gap theorem has a separate computational premise and ends below 4 × 10¹⁸. [Conditional Lean provider](https://github.com/sthubbar/goldbach-lean/blob/f003a97d7598923787920723668d62c16c82b81e/entries/dudek2014/LeanLab/Dudek2014/SigmaHSWDownstream.lean) [Current inventory](https://github.com/sthubbar/goldbach-lean/blob/93b86c05bb441be2ac0b3f06cc4c8624f8e8d0eb/README.md) [Dudek's paper](https://arxiv.org/abs/1402.6417)

For odd n ≤ 10²⁷ take x = n−4. The width is at most about 2.503166 × 10¹⁵, so B = 2.51 × 10¹⁵ covers the width plus 4. For n ≤ B+3 choose 3 directly. Beyond that range any prime with `4 ≤ n−p ≤ B` is odd, and the difference is even. At the alternative analytic cutoff 10²⁰, the same width is at most about 5.863485 × 10¹¹, allowing B = 5.87 × 10¹¹. These round-number margins are arithmetic screens awaiting Lean checks. The separate `rh_gap` agent reviewed the zero-count providers and reports unresolved `sorry` in the candidate PNT+ HSW source. Closing Dudek by another estimate may use the proved smoothing argument directly without formally deriving HSW's sharp published count.
