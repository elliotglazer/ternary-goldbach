## Runtime monotonicity is correctly limited

Ceiling division by eight, addition and multiplication of nonnegative integer byte lengths, and their minimum are nondecreasing in those capacities. Hence every displayed product, exact-addition and round-witness component is nondecreasing in p. The same holds for the standalone addition component. With nonnegative fixed tariffs, each specified three- or four-product runtime core is nondecreasing.

For a fixed allowed set and fixed mode, choosing the smallest allowed p above each r therefore minimizes that runtime core. This does not minimize the complete workload.
