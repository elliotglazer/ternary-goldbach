## 2. A compact typed receipt

The following is the minimum logical structure, with index-implied arrays and shared constants allowed.

* A manifest fixes actual conductors, primitive labels, inverse/parity maps, H(c), the source function and the one chosen root phase epsilon_chi. Exact identities support those fields; hashes only identify their evidence.
* Value blocks bind rational node grids, evaluator/normalization, cutoffs and precision, source centers/radii and arithmetic dependencies. A point may use a direct evaluator, a character transform, or a proved interpolation circuit. Different backends may share one node only through the same actual function identity.
* Shared phase objects bind epsilon_chi and conductor/parity/time factors. A strict sign record references a value and these objects, gives a real enclosure, and checks either lower>0 or upper<0. An unresolved enclosure is never a zero or a sign.
* Main and auxiliary runs list increasing exact endpoint IDs with alternating certified signs. Nonempty runs have disjoint interiors, checked also across tiles and at shared endpoints. The interval count of a run of m vertices is m-1. A packed alternating pattern does not replace proof of the individual strict signs.
* A critical-line lower-count object records the main runs and optional additional proved multiplicity. Its default central contribution is0, using only nonnegativity of multiplicities. It does not claim central nonvanishing. Positive central multiplicity needs a valid source proof; a zero-containing enclosure is insufficient. Where the actual self-dual functional equation has root number -1 and a holomorphic nonpole center, that equation can supply a lower multiplicity1 without determining the exact order. No approximate root-phase box can establish that sign identity.
* An orbit closure binds rational T>=H(c), T>50, h>0, canonical count upper bounds, auxiliary weights, K and a strict rational surplus. The exact-count and finite-RH-only outputs have different tags, as below.
* Global acceptance checks a complete partition of the required manifest into accepted orbit records. Missing labels and unresolved records remain failure. It does not depend on a process success code.

For k disjoint ordinary sign intervals in b nonempty runs, there are exactly k+b distinct endpoints. This lets the checker count a whole alternating run without a theorem per zero. Shared boundary signs are deduplicated by character, phase and exact height. Gaps between endpoints may contain more zeros; the upper-count test, not a spacing assumption, decides whether that is harmless.

All count arithmetic can stream. For auxiliary intervals with right endpoints v_i and top H=T+h,

    W_channel = k_aux H - sum_i v_i.

Real characters use twice this weight; nonreal pairs use one weight from each positive channel. Common dyadic endpoint denominators permit integer sum accumulators with an added logarithmic count-width allowance. If arbitrary rational heights are allowed, their denominator costs must instead be included. A claimed aggregate W is accepted only after checking its disjoint sign-run evidence or a separately proved lower-zero-count object.

## 3. Shared post-transform phase work

The reviewed finite Hardy proxy is

    P_chi(t)=Re(epsilon_chi exp(i phi0(c,a,t)) L(1/2+it,chi)),
    phi0(c,a,t)=(t/2)log c+f_a(t).

Here f_a is exactly the conductor-independent remainder of the reviewed elementary phase formula. The positive cosine identity proves equality of signs with the actual Hardy function. Its bounded analytic phase discrepancy is not an additive numerical error floor. It also does not make P an interchangeable source function for a sampling theorem.

This separation permits the following cache schedule, conditional on explicit error checks. Compute f_a(t) and its cis once per global height and parity: at most255978 objects on the current main grid. Compute log c once per conductor. The factor exp(i t log c/2) can be produced directly or by a checked height recurrence with step cis(Delta log c/2), starting exactly at1. The latter has at most125400 step objects and2735098055 updates. At most5470446910 parity/conductor/time products combine it with cis(f_a(t)). These are upper inventory counts, not supplied phase certificates. Their required precision depends on the sign-value budget and the magnitude of L; the seed's140-bit recurrence is not automatically sufficient for this different consumer.

The root phase epsilon_chi is fixed per character and can be refined/reused. Its finite Gauss sum, branch definition and enclosure proof are a separate setup bill. Equal conductors do not make different character root phases equal.

The reviewed inverse-channel adapter permits defining the partner phase as the conjugate of the representative's phase. If earlier data instead used independent phase choices, their exact constant sign relation must be supplied before reuse; no per-height branch switching is permitted.

For a concrete sign-radius interface, let Lhat have norm error r_L, epsilon_hat have error e, and qhat approximate the unit exp(i phi0) with error f. Let M>=|Lhat| be a checked rational bound, for example the sum of coordinate absolute values. If the final arithmetic has error r_A, then

    |P-P_hat| <= r_L+M*(e*(1+f)+f)+r_A.

This formula charges shared input errors once. Accept a sign only when |P_hat| exceeds this complete real radius. A simple finite circuit forms epsilon_hat*Lhat and then the real projection against qhat. It uses one general complex multiplication and two real products plus a real subtraction per requested point, with all their rounding charged. Alternative fused circuits can be priced on the same contract. If actual completed real values are already certified, this overlay need not be repeated.

For interpolation, the existing Gaussian/sinc theorem requires its actual completed source Y, not the elementary sign proxy P. ## 4. Exact closure and economical auxiliary collection

Use the accepted closed-count/a.e. convention. C_chi(T) counts actual nontrivial zeros with |Im rho|<=T, including multiplicities and all real zeros. Main critical-line evidence supplies K<=C_chi(T). For nonreal chi, K is the sum of the two positive channel counts plus the one central lower multiplicity; for real chi it is twice its positive count plus its central contribution.

For H=T+h, supply

    Abar >= integral_T^H 2 theta_(a,c)(t)/pi dt,
    Bbar >=42+(693/100)log(cH/(2pi)),
    W <= integral_T^H added_zero_count(t) dt.

The source theorem gives C_chi(T)<=(Abar-W+2Bbar)/h. Abar uses the canonical analytic log-Gamma phase. Substituting phi0 here without an integral error would be false.

Keep the output requirement explicit through an integer d:

    Gamma_d=h*(K+d)-Abar+W-2Bbar >0.                 (C)

For d=1, integrality proves C=K. This is exact-count saturation. The frozen `TURING_SPECTRAL_SURPLUS_REDUCTION` derives a d=2 finite-RH-only adapter, currently under separate independent review: an off-critical zero is paired with1-conj(rho) in the same character, at the same ordinate. The distinct pair contributes at least two positive multiplicities outside the K critical-line witnesses. Equal reflected multiplicities are stronger than needed. Once that adapter is accepted, (C) with d=2 excludes every off-line zero while allowing one unaccounted critical-line count, including at the closed boundary. It must not be labeled C=K or consumed by an exact count/reciprocal-sum theorem. Until the separate source audit is accepted, d=1 is the existing closure rule.

The default central lower count0 is sound for either rule: real/central zeros stay in C. Stronger central evidence is an optional way to improve K. The current large-branch finite-RH target does not independently require exact zero counts. Principal and small-conductor consumers with stronger count data remain separate.

For fixed T,h,Abar,Bbar,K, the precise auxiliary target is

    W > Abar+2Bbar-h*(K+d).                          (W)

Every new certified interval adds a nonnegative weight H-v. Stop collecting auxiliary data as soon as (W) holds. No full auxiliary zero list or fixed number of zeros is required. Earlier intervals have larger weights. Refining a valid right endpoint from v to v'<v gains v-v'; tightening Abar by e or Bbar by e gains e or2e. A new disjoint main witness gains h. Those are exact improvement rates and can guide a producer without claiming that any requested witness exists.

Auxiliary evidence may instead be disjoint complex zero-count boxes wholly in the positive strip with upper ordinate v<H. A count m adds m(H-v), even if the zeros are multiple or off-line. Their argument-principle proofs and disjointness from other counted objects are extra costs. Such boxes cannot replace critical-line main evidence merely because they are narrow.

This is the smallest sufficient *acceptance* strategy: selected main lower evidence, only enough auxiliary lower weight, and one strict surplus test. It is not a uniform bound on producer work. Increasing h changes Abar and every weight and requires a new test. No h alone guarantees success, and no numerical zero-separation or margin assumption is added.

## 7. Can this layer dominate the arithmetic savings?

Let C_post be the sum of the phase, interpolation, retained sign, count, extension, repair and I/O costs above, measured with actual operand widths. The total is C_seed+C_residue+C_transform+C_post plus the analytic/proof foundation and other branches. No constant price per zero or unconditional bound on C_post has been established.

For scale only, the fixed-order primitive pruning saves758442059397608 general complex products and1591950947370460 complex additions relative to full mixed transforms. Divided by Q, these are respectively between11.461550 and11.461551 products, and24.057507 and24.057508 additions per nominal coarse output. The P24-to-P20 residue change saves398052393027072 reciprocal-scale/addition stages of each kind, between6.015353 and6.015354 per Q. P28-to-P27 saves only about.031253 head-scale/addition stages of each kind per Q, plus the smaller shift-stage bill.

These are category-normalized break-even quantities, not equal-time operations. They show why even a modest additional per-output interpolation or refinement cost can match recent savings in operation count. The dense auxiliary warning is larger still. Conversely, strict sign testing and run/count arithmetic alone are much simpler than repeated special-function evaluation; shared phases and selected auxiliary weights can remove a large naive per-zero bill.

If the post-transform contract and work are identical for two candidates, C_post cancels in their absolute difference. It only reduces the percentage speedup. Different centers may change which signs pass at fixed radius, and different interpolation/source floors may change refinement work. Then an actual incremental post cost Delta_post reverses a candidate saving Delta_pre precisely when Delta_post>Delta_pre in the chosen full cost model. No present margin or repair distribution determines that inequality.

The next useful evidence is therefore a complete sign/closure packet with its dependency unions and unresolved queue, not another isolated easy value or transform throughput result. It should record the exact surplus and every additional domain requirement. This note supplies the interface and deterministic inventory needed to compare such packets; it supplies none of their spectral truth.
