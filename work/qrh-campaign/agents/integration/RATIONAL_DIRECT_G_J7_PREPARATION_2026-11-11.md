## Deterministic omitted gates

Each real rounding of x=p/q to grid2^-g computes m=floor((2*p*2^g+q)/(2*q)) and checks `(2*m-1)*q <= 2*p*2^g < (2*m+1)*q`. The complex gate rounds real then imaginary. Gate order is fixed by the source loops. There are no gates in exact sums or polynomial products. Each leaf resets a fresh digest; exact n1 branches have the empty digest.

The digest is SHA256 of sequential gate records. A record consists of five signed integers `(g,p,q,m,remainder)`, where remainder=`2*p*2^g+q-2*q*m`. Each integer is encoded as its canonical ASCII decimal followed by a newline. No tags, separators or JSON are added. The gate summary is `{count:integer,sha256:uppercase-string}`. This digest is a consistency check only. An independent template must reconstruct and verify every witness before comparing it. The exact p/q is reduced by Fraction before hashing. Shared order: log2 all inner gates, atan(1/5), atan(1/239), canonical pi; the raw log2 is not canonically rounded. Complex Horner includes two coordinate gates even when the imaginary coordinate is zero. Real log/atan/squaring gates contain one coordinate.

Exp order: real Horner (one coordinate each,512updates), four real squares, cis Horner (real then imaginary,512updates), final complex product (real then imaginary) at canonical grid. No gates are added for input scaling or period reduction. Per log:512 affine gates, one final2t multiply, one canonical assembled gate. Each head/correction/g has two coordinate gates.
