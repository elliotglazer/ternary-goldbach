## 5. A model that charges each layer once

For each objective separately, such as generation, ordinary proof production or checking, use

    C = L_fixed
        + sum_cache_lifetimes Phi(cache setup DAG at its actual precision)
        + Phi(source + residue evaluation + guarded normalized transform
              + actual Y completion + negative adapter
              + query kernels/interpolation + count evidence)
        + C_small + C_principal + C_finite + C_analytic_join
        + C_repairs + C_transport_and_storage.                    (1)

Phi is a declared price functional on a complete operation/proof DAG under ONE radix, digit representation, cell signature, rounding schedule, source-binding plan and chunk policy. The function can use operand widths and categories. It is not automatically a constant price per arithmetic event. If Phi already expands products into the full PA proof schedule, do not add the old product-event subtotal as a second independent cost.

L_fixed includes genuine ordinary table/range/decoder and generic algebra proofs, the chosen definition/library construction and allowed-foundation closure. Table declarations checked once do not make local closed-instance applications free. The named-header and stock-local-visibility results remove specific metadata/name obstructions, but do not prove the50,331,648 w12 arithmetic facts or establish all proof-body/store/file limits.

The expanded-byte C108-640 candidate uses the reviewed padded binding schedule and source grammar. Under the same term/table conventions the zero-carry lift can replace the full lift because its conclusion is identical. Charge the actual E4zero fact and range completeness needed by the surrounding producer. The public binding addition and padded-base increment are charged once: either substitute the new base conclusion or add12n to the old fresh-conclusion schedule, not both. Signed branches, canonical zeros, output ranges, rational or dyadic rounding witnesses, exact shifts and actual public source transport remain part of Phi.

Named aliases are an alternative encoding for Phi, not a discount applied afterward. The checked canonical definition body, exact head/UTerm identity and URef sharing, byte-to-name conversions, named-radix specialization and source exit must all match. The zero-carry named-header composition has not been supplied as a complete matched fold here. The proposed fixed-width named-body successor is not automatically the canonical design's setup count.

Similarly choose either the stock row/padded schedule or the streamed local-word block schedule. The latter has new closed chunk equalities and exact word/place join producers; it does not retain the old row-command subtotal while subtracting the new one. It preserves the public final high carry. A trusted continuing-state checker must implement exact publication/import and definition lifetime. Stock local declarations are checked and globally callable, but their local expression/proof references reset. In stock non-BARE code a Sorry-tainted declaration may advance the frontier before final file rejection; no clean continuing export may use that fact. No producer hash or checkpoint flag is an ordinary theorem.

Generation pays unsuccessful attempts actually performed. Checking may retain only the successful dependency union if every needed source/error/count object is genuinely certified and bound. No repair rate or termination claim is assumed, so a final expected-cost model still needs a disclosed planning distribution or actual observations. This audit supplies neither.
