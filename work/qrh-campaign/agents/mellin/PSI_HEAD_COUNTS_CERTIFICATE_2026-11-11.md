## 1. Function and Euler–Maclaurin enclosure

The counted function is the source's entire `TernaryGoldbach.Explicit.zetaF`: it equals `(s-1)zeta(s)` away from1 and is1 at1 (`Explicit/ZetaGrowth.lean:17–30`). Thus its zeros in the rectangle below are exactly the nontrivial zeta zeros, with equal orders. Zero and one are not added zeros; the first negative even trivial zero lies outside the rectangle.

The EM formula and uniform complex remainder were already independently reviewed in `moebius/ZETA14_RECTANGLE_REVIEW_2026-11-11.md`, for the frozen zero-sum evaluator `F7748958058E921636E4372BC74C3B55C5AE24E062B27C648907482BDFE71955`. The present implementation rebuilds all Bernoulli coefficients, logarithms and powers for its own parameters. It does not mutate the height14 evaluator's globals.

Here N=500, M=32, B=N+1=501. Define the finite entire function

\[
g(s)=(s-1)\left[\sum_{n=1}^{N}e^{-s\log n}
+\tfrac12e^{-s\log B}
+e^{-s\log B}\sum_{k=1}^{M}\frac{B_{2k}}{(2k)!}
(s)_{2k-1}B^{1-2k}\right]+e^{(1-s)\log B}.
\tag{1}
\]

The pole cancels before evaluation. Bernoulli numbers are generated by their exact rational recurrence. For actual contour points Re(s)>=sigma0=-1/10, the reviewed EM estimate is

\[
|zetaF(s)-g(s)|\le
\frac{4|s-1|\,|(s)_{2M}|B^{1-\sigma_0-2M}}
{6^{2M}(\sigma_0+2M-1)}.
\tag{2}
\]

The condition sigma0+2M>1 holds. For a block centered at c with half-length h, replace |s| by S=|c|+h, |s-1| by S+1, and the rising-factorial norm by `product_(j=0..2M-1)(S+j)`. This gives a uniform block error E_EM. These replacements are inequalities for the entire block, not endpoint evaluations. Actual contour points obey the exact real-part condition even if an outward-rounded input ball extends slightly beyond it.

## 2. Taylor blocks and the second explicit remainder

Direct interval evaluation of every exponential over a long panel loses cancellation. Instead each path is split into blocks of length at most1/5, so h<=1/10. At each rational center c, FLINT ball power-series arithmetic computes the first K=24 Taylor coefficients of the finite entire expression g. These coefficients retain cancellation before a segment is intervalized. No zeta function or gamma function is called.

The Taylor truncation error is bounded separately from (2). Put R=1, S_o=|c|+1, sigma_o=Re(c)-1 and

\[
\begin{aligned}
M_o={}&(S_o+1)\left[\sum_{n=1}^N n^{-\sigma_o}+\tfrac12B^{-\sigma_o}
+B^{-\sigma_o}\sum_{k=1}^{M}\left|\frac{B_{2k}}{(2k)!}\right|
\prod_{j=0}^{2k-2}(S_o+j)B^{1-2k}\right]
+B^{1-\sigma_o}.
\end{aligned}
\tag{3}
\]

This bounds |g(s)| on |s-c|<=1 term by term. Although this outer disk may extend to Re(s)<-1/10, no EM remainder assertion is used there: g itself is the finite entire expression (1), so (3) is valid everywhere.

Cauchy's coefficient bound now gives, for every actual point of the block,

\[
\left|g(s)-\sum_{j=0}^{23}a_j(s-c)^j\right|
\le M_o\frac{h^{24}}{1-h}.
\tag{4}
\]

Add (2) and (4). The result is a uniform disk radius for zetaF minus the ball-coefficient Taylor polynomial. Enlarging that disk to a coordinate square is conservative. The polynomial is evaluated by interval Horner arithmetic over each candidate subpanel. Subdivision reuses the same coefficients and error bound; it does not silently recompute a smaller remainder without justification. All required images are certified by open coordinate half-planes.

FLINT's `acb_series` arithmetic is used only for finite expression arithmetic and elementary exp/log, under its external interval enclosure contract. This is computational evidence, not a proof of the interval library. The Cauchy theorem, EM remainder, and all arithmetic operations need a kernel-checkable replay for eventual Lean use.

## 3. Rational grid and shared paths

Let n0=14*1024 and recursively

`n_(j+1)=min(1500*1024,n_j+floor(n_j/100))`, `t_j=n_j/1024`.

This produces471 cells and472 checkpoints, starting at14 and ending exactly at1500. All endpoints are rational with denominator1024 before further panel subdivision. The inequalities `t_j<t_(j+1)` and `t_(j+1)-t_j<=t_j/100` are checked exactly; the latter is not needed for soundness, only to explain grid density.

The rectangle for each checkpoint is

`[-1/10,11/10] + i[0,t_j]`.

Its bottom goes left to right, its right side upward, its crossbar right to left, and its left side downward. A single bottom path is reused. Left and right vertical paths are certified upward once, in successive checkpoint intervals; their signed crossing sums accumulate. Only a new crossbar is needed at each checkpoint. There are1417 stored paths in total: one bottom and three for each checkpoint.

Input geometry is exact. Replay checks every block's parent path, endpoints, direction, length and adjacency, then every panel's corresponding properties. Every block is used exactly once in the stored path decomposition. Shared input vertices have identical rational image vertices across every incident path, not merely within one rectangle.

## 4. Half-plane homotopy and complete counts

For each accepted panel, its actual zetaF image and both rational polygon endpoint values lie in the same open coordinate half-plane. The image inclusion uses the Taylor-plus-EM enclosure above. The rational endpoint values are shared at adjacent panels. Convex interpolation therefore supplies a nonzero homotopy from the actual contour image to the rational polygon, continuously across every junction.

Replay need not trust how a rational image vertex was originally selected. It checks the required half-plane membership for that vertex on every adjacent panel. That condition, together with actual endpoint membership, is enough for the common homotopy.

The polygon's crossing contribution is computed with exact rational determinants and half-open crossings of a fixed ray. Upward crossings of the positive real ray contribute+1 and downward crossings-1. A straddling edge with determinant0 is rejected. Reversing an edge negates its crossing contribution. For checkpoint j the exact winding is

`cross(bottom)+prefixCross(right)+cross(crossbar_j)-prefixCross(left)`.

These four paths form its entire positively oriented boundary. Their shared vertices and exact partition checks make this equivalent to constructing the full closed polygon. No numerical phase unwrapping is used.

The argument principle identifies this winding with all interior zeros of the entire zetaF function, counted with positive multiplicity. The half-plane witnesses separately exclude boundary zeros. Therefore the resulting count is also the closed positive-ordinate count `0<gamma<=t_j`; zeros exactly on the requested top edge would have caused the certificate to fail. The bottom edge is certified nonzero, so no real zero is omitted. The real sides lie outside the critical strip, and the usual unconditional classification of zeta zeros handles the carrier. No finite RH assertion is needed.

The base rectangle gives N(14)=0. Counts are also checked to be nonnegative and nondecreasing. These consistency checks do not substitute for the complete contour proof; each checkpoint has its own assembled nonzero boundary and exact winding.
