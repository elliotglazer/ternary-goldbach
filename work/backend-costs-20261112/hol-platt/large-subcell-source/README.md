# Using a finer shared table in band 1

The stored polynomial in the original variable z is valid for |z|≤1/4. Divide the fine cell into K equal parts. Select the nearest t=i/(2K) and put s=2K(z−t), so |s|≤1/2. The coefficient of s^l in the original polynomial is (2K)^(-l)∑_{j≥l} binom(j,l) C_j t^(j−l). The script bounds its contribution using |t|≤1/4 and the previously derived uniform magnitude of each stored coefficient. It chooses a degree with tail under 1/64 grid94 unit per coordinate. Rounding each new coefficient on grid102 adds less than 1/256 grid94 unit after geometric weighting. A final nearest rounding returns to grid94.

The new table can be reused across conductors. At K=1024 the workload-weighted degree is 6.31 and there are about 910 requested complex outputs per precomputed complex coefficient if each shared entry is built once. At K=4096 the mean degree is 5.66 and that ratio drops to 250. The precomputation includes separate ownership at original cell boundaries and both endpoints. The counts assume complete tables for every height, with one owner per entry. A sharded schedule can produce duplicates. Rates for table generation, transport, reordering by conductor and kernel lookup are open.

The revised band-1 source bound consumes 0.430731 of its analytic error allowance when the inherited remaining terms are retained. The old bound was 0.508378. The comparison charges conversion of all twenty original coefficients and the new terminal rounding. Nine spot checks at genuine residues agree with the original rounded output.
