# Exact Kronecker convolution for the small-family time transform

The zero-extra-node sign-only schedule has 18,477,108 character transforms across 7,499 conductors. A full-integer implementation would replace the old 89,858,217,607,168 dense normalized butterflies with 55,431,324 multiplications of large signed integers, 2,405,711,864,874 prechirp slots, and 1,775,431,871,117 requested postchirp samples. These are counts for an alternative circuit. A machine or prover that verifies a large multiplication by schoolbook expansion could spend far more time than on the original FFT.

## Binding to the sign ledger

For each conductor the manifest gives N, the last requested index m, and the theta-specific time precision. The reviewed small-family contract bounds each exact stored Gaussian coefficient center by B=2W²+1, with W=40,000,000/θ for odd conductors and 80,000,000/θ for even conductors. These are sufficient bounds for the actual coefficient arrays, not observed maxima. They concern the centers of the raw polynomial after canonical phase selection. Their existing analytic errors are already charged upstream. J=ceil(25N/192); signed input support is −J..J, so L=2J+1. Each positive sample k=0..m must approximate the real, unnormalized U with error below T=7 eps N Delta/2816, eps=2^-82/3^θ, Delta=5/64.

For p_j=exp(πij²/N), N even, p_j is N-periodic and p_k p_j conj(p_(k−j))=exp(2πijk/N). Prechirp the signed input A_j. For k=0..m, only differences −J..m+J occur. Store this many consecutive kernel values, K=L+m. Shift the input and kernel indices by J. The desired coefficients of the ordinary linear product have indices k+2J. The full product contains L+K−1 coefficients. No size-N circular FFT or N-length zero gap is needed.

Let u=2^-p. Regrid each exact stored center with complex error at most u. Enclose each rounded chirp within u of the true unit. Round the prechirped complex input once with error at most u. With the conjugate kernel and the final chirp exact as dyadic arithmetic, the error per input contribution before normalization is at most

    (B+u)(1+u)^3−B + u(1+u)^2 ≤ (7B+12)u,   0<u≤1.

The inequality follows by expanding the product and using (1+u)^3−1≤7u. Summation is exact. Divide by N exactly and round the normalized output to grid p. The raw error after multiplying by N is bounded by [L(7B+12)+N]u. This pays for both an initial regrid of the original Gaussian coefficients and terminal normalized rounding. A dyadic denominator handles normalization without an extra gate before that final round. price.py uses p=ceil(log2([L(7B+12)+N]/T))+1 and checks the strict comparison by fractions on each row. The extra bit is conservative. Every row saves 3 or 4 fractional bits relative to its original time-gate precision. The interpolation threshold, phase, positive branch conventions, source coefficients and sign decisions remain the responsibility of their original interfaces.

## Integer widths and costs

With S=2^p, each signed prechirped coordinate has magnitude at most X=ceil((B+1)S). This uses the checked inequality u(B+2)+u²<1. Each conjugate-kernel integer coordinate is bounded by Y=S+1. Real and imaginary parts can be recovered from the three real integer convolutions re·re, im·im and (re+im)·(re+im). The largest signed coefficient magnitude in any of them is at most 4LXY. Choose byte-aligned width w with 2^(w−1)>4LXY. Substitution of 2^w for the polynomial variable then allows unique signed centered-digit extraction. Signed encoding, carry correction, arithmetic recombination and keying the chirp cache are essential. A packed product interpreted as unsigned coefficient fields without correction can fail on negative coefficients.

The ordinary products have input slots of Lw and Kw bits and a result allocation bound of (L+K)w bits. Each kernel row can be built once per genuine shared cache lifetime. Hermitian symmetry permits storing only J+1 original source pairs. Since p_(-j)=p_j, prechirping two conjugate source values generally gives two distinct products. The counts charge all L complex prechirp slots. Exact DC and trivial rotations may be specialized separately. Only the real postchirp coordinate is required by this sign route.

For c=10000, N=524,288, m=84,224, J=68,267, θ=64, and B=3,125,000,000,001. The sufficient p is 240 relative to the old 243; the original raw output magnitude exponent is 59. At w=544 the two real product operands consume 9,284,380 and 15,011,612 bytes and the result allocation is 24,295,992 bytes. There are 1,600 primitive character lanes. In contrast c=4, N=2^30, needs individual operands up to 40.13 GB and a single result up to 61.66 GB. Large rows likely require blocked middle products, separate carry/guard proofs and revised counts to fit normal working memory. Pinning exact outcomes of giant machine integer operations inside a proof kernel has not been demonstrated.

The field width range over all rows is 536–744 bits. Across the 55,431,324 real products the nominal input capacities total 1.411 PB and result capacities total another 1.411 PB, decimal. These are summed payload capacities, **not measured memory traffic**. Keeping shared kernels resident may reduce reads. Packing, base conversion, FFT multiplication scratch, repeated memory passes, extraction, certification and transmitting results may increase traffic. Original input coefficient encodings and their denominators can exceed these widths before the first regrid. The original code's per-conductor and seed/root precision metadata are not bounds on proof-object memory. The count charges each existing character exactly once and does not compose this alternative with separate half-transform, paired-character or pruned-FFT savings.

## Bounded multiplication controls

With 544-bit fields and the c=10000 output/support proportions, one general exact FLINT fmpz multiplication of dense deterministic random operands took 0.0030, 0.0128 and 0.0523 wall seconds at nominal N=4,096, 16,384 and 65,536. CPU clock granularity is coarse at the smaller sizes. The largest test operands were 1.16 MB and 1.88 MB. The benchmark used one FLINT thread, verified the product modulo 65,537 and timed only the multiplication. Its inputs are synthetic. No actual Gaussian array, chirp production, packing, extraction, formal proof or full production-row timing was measured. The test stopped below N=2^19.
