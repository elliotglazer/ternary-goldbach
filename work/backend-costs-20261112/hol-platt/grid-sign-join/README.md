# Checking the conductor-10,000 counts from one sample grid per character

HOL4 proved `even_pair_from_samples` and `odd_pair_from_samples`. For each character the regular sign bits and the 114 off-grid checks across the four characters use the same named compressed sample table. Both counts use the exact same sign packets that the channel checks accepted. The two pair tests give the previously computed bracket counts 31,760 and 31,762 with the 50-unit auxiliary window and the supplied phase and allowance. [Combined theorem](JoinCountScript.sml) and [build log](joined07_JoinCount.log)

Each group of 64 samples uses a shared power of two. The producer increases precision only where a sign or interpolation margin fails. Across 340,484 values including the halos, the coefficient fields cost 13.09 bits per sample, before the block metadata. For an off-grid point, the checker uses the prior exact kernel, a margin for the interpolation error, and an additional allowance of five times the largest sample unit times the kernel denominator. All four channels passed. The check linking raw 220-fractional-bit samples to the compressed inputs currently runs in Python. The analytic transfer to actual L-values remains open. [Compression and error thresholds](prepare.py) and [HOL definitions](GridSignsScript.sml)

The four HOL processes consumed 159.56 CPU seconds. Reading, encoding and evaluating the channels accounted for 66.61 of those seconds. The actual four evaluations took 8.15 CPU seconds. Input encoding varied sharply for character 6667 under local load. Rebuilding the common kernel table took another 30.05 seconds. A separate process checked and exported the combined theorems in 22.76 seconds. These timings exclude production of the sample grids and earlier numerical count proofs.
