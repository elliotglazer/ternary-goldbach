# Reusing one table of Hurwitz coefficients across heights and conductors

The band-1 experiment uses actual stored coefficients at height indices 1–32 and 6337–6368. In the fastest eight-height configuration, a stock HOL4 kernel consumed the same coefficient block across eight real conductors in 7.87 µs per complex output at low heights and 10.67 µs near the top of the band. These numbers include the fixed kernel work for one block. The zero-to-eight marginal measurements were 6.26 and 7.25 µs per output. One cell of the original 1,025-cell grid and eight neighboring even conductors were tested. [Kernel timings](rates.json) · [Run log](slab03.log)

## Change to the arithmetic

Write z=r/v, with |z|≤1/4. At each reduced residue, start with w₀=Q=2^112 and set wⱼ₊₁=nearest(wⱼr/v). The recurrence has error at most 2/3 grid units for each power. The constant weight is exact. After shifting the original mixed-grid Taylor coefficients Cⱼ to grid94, evaluate ∑Cⱼwⱼ and divide by Q once. The previous magnitude envelope bounds the error before final rounding by 0.00001414 grid94 unit per coordinate over band 1. The revised complete amplified source bound is below 0.426206 of the allocation 2^−82. The corresponding old bound was 0.508378. That calculation retains the original target remainder, finite translation and coefficient conversion. It omits the old intermediate Horner roundings and charges the new weights and terminal rounding. One column packs both coordinates at 8 or 32 heights in radix 2^232. A scalar weight multiplies the whole column. After adding a common bias, 112-bit right shifts in a balanced tree compress the integer to 120 bits per coordinate. Each retained coordinate is a biased signed grid94 center. The independent fixture program reconstructed every digit and checked the polynomial against exact rational Horner evaluation. The result differed in no rounded coordinate in the single-conductor cases. The analytic bound allows some coordinates to differ elsewhere.

The first kernel runs compared every packed result to the independently generated exact vector for conductor 131068. The reuse run used a deterministic digest of all output digits and checked it in HOL for each length of the conductor prefix. This measures the cost of consuming the results internally. Only the first run proves equality to the entire external comparison vector. Neither run proves the general analytic weight error theorem in HOL. The timed source columns were supplied as packed integers. Building them from admitted Euler–Maclaurin tables, routing each output to the next transform, and establishing the signs remain separate.

## Cost sensitivity

For 32 adjacent conductors and eight heights per block, the manifest fold counts 3,199,451,400 calls over the original cells. At the two measured marginal prices, including the kernel's fixed control work once per call, the first band would cost 82,621 or 99,737 core-hours. Applying each endpoint price to all heights gives two sensitivities, not an uncertainty interval. This schedule extrapolates conductor reuse from eight to 32. It excludes statement preparation, table loading and the production output consumer. Holding all unit outputs of one such block in a compact buffer requires at most 837,030,720 raw bytes. One packed write of every band-1 output totals 1.342 PB. Actual HOL object space, scattered writes and the effect on process lifetimes require measurement.

The same fold exposes the price of an overly literal checkpoint design. With this group size, reloading a raw state pair for every eligible base once per height block would deliver 535.6 billion pairs over all five bands, and updating the whole raw pool independently within each group would cost 4.28 trillion updates. Those numbers describe one possible ownership schedule. A single height-major raw producer or a shared table can change them and introduces its own transfer and lookup costs.
