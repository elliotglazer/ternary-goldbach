## Spectra and samples

We used the published 640-extra-node schedule's tilt 64 and length 524,288 for all comparisons. Shorter guard tests read prefixes of this same tilt and sampling run. With step 5/64, period P = 40,960 and b = π/4 − 64/6630, the coefficient at x = 2πj/P is

    2 εχ q^(-k/2) exp(k(x+ib)) Σ n^a χ(n) exp(-π n² exp(2(x+ib))/q),  k=a+1/2.

The unit phase εχ is the reciprocal of a fixed square root of the actual Gauss root number. Both inverse characters were evaluated separately. This run uses four direct character sums at each frequency. Production cost models that share a character transform across all primitive labels use different arithmetic.

For each retained j from 0 to 68,267, put d = π exp(2x) cos(2b)/q. The odd absolute tail after m terms is at most (m+1) exp(−d(m+1)²)/(1−r), where r = (m+2)exp(−d(2m+3))/(m+1). This also bounds the even tail. The program checks d(m+1)² > 256 and r < 1. It evaluates only the four nonzero residue classes modulo 10, using quadratic-exponent recurrences restarted every 24 terms to control interval width. It adds the tail before rounding every coefficient. Each coordinate of the true coefficient lies within two units of its stored integer on the 256-bit grid. It also checks quadratic vertices for pairs between probes. Its proposals have no proof authority. Failure to discover enough zeros would leave the count open.

For verification, the exact polynomial U built from the dyadic coefficients has, in coarse-index coordinates, derivative bound C(2πJ/N)^r with C = (2J+1)[2(80,000,000/64)²+1]. ## Why a width of 25 can also suffice

The strict integer test is U < K+1. The width-50 window passes with the project's paper-level per-channel allowance 18. At width 25 the two differences U−K are 1.6715 and 1.6278. They still prove exact counts if we establish the following additional parity fact.

Take a nonzero real-analytic Hardy normalization on the line, meaning a function that is not identically zero. Require strict signs at 0 and T on each of the two positive channels. Each critical-line zero of multiplicity m changes the sign by (−1)^m, since its local real-analytic factor is nonzero. Finite multiplication over the zeros in (0,T) shows that the endpoint signs determine the parity of their total multiplicity. Nonvanishing at 0 and T excludes critical-line endpoint roots. Conjugation identifies the inverse character's positive roots with the original character's negative roots, preserving multiplicity. Off-line zeros of the original completed function occur in distinct pairs under ρ ↦ 1−conj(ρ), including those at ordinates 0 or ±T. Thus the parity of the entire closed count C equals the sum modulo two of the endpoint sign differences.

For these streams every main bracket flip was counted. The extra samples immediately inside 0 and T match those endpoints on each channel. Thus K has the required parity. Since K ≤ C and C is an integer of that parity, U < K+2 gives C = K. If the endpoint signs or their agreement with the counted parity are unavailable, this exact-count argument does not apply. The existing two-unit *finite RH* test has weaker premises and, on its own, permits an unaccounted critical multiplicity.
