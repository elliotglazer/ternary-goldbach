# Large-family Hardy coordinate conventions

For a primitive character χ modulo q, write a=(1−χ(−1))/2, s=1/2+it, g=(s+a)/2, and τχ=Σχ(u)exp(2πiu/q) over units. The character transform in the fixture computes Dχ=Σχ(u)ζ(s,u/q)=q^s L(s,χ). The same positive character transform on exp(2πiu/q) gives τχ. Both sums are unnormalized. On each cyclic component the positive character index k corresponds to the negative forward Fourier index −k modulo its order. At positive height the Hurwitz inputs are complex, so conjugating the spectrum changes the input convention too. [Platt §§2.1, 4](https://arxiv.org/pdf/1305.3087v1)

Set Wχ=τχ/(i^a√q) and Cχ(s)=(q/π)^g Γ(g)L(s,χ). The primitive functional equation Cχ(s)=Wχ C_conjχ(1−s), conjugation of the completed functions, and 1−s=conj(s) imply Cχ(s)=Wχ conj(Cχ(s)). The fixture chooses a unit εχ with εχ²Wχ=1. Thus H=εχ Cχ(s) is real, including at a zero. Platt's real function equals H times exp(πt/4)(q/π)^(−1/4−a/2) with this same εχ. This multiplier is strictly positive. The opposite choice of εχ reverses all signs of the character together and preserves sign changes. [Platt §2](https://arxiv.org/pdf/1305.3087v1) [Primitive functional equation](https://dlmf.nist.gov/25.15.E5) [Gauss sum convention](https://dlmf.nist.gov/25.15.E6)

The author's noncyclic implementation combines q^(−1/2)(qπ)^(−it/2) with the parity-dependent gamma factor, exp(πt/4), and the character phase. The conductor factor equals q^(−s)(q/π)^(it/2). This source demonstrates the author's convention. Identifying the exact executable in the historical run would require its build provenance. [Platt's implementation](https://github.com/djplatt/code/blob/1f19fcbefa33d2fe5949ddbcd4d3df75deca6819/l-func/int-l-func5.11.cpp#L566-L631)

For q=10004 the input exponents j4,j41,j61 index generators −1,6,2 modulo 4,41,61. The flat index is j4+2j41+80j61. The primitive frequencies have k4=1, 1≤k41≤39, 1≤k61≤59 and a=(1+k41+k61) mod 2. These give 2301 characters per height. The flattened primitive output j=59(k41−1)+(k61−1) has a=1−(j mod 2). The paired character has frequencies 40−k41,60−k61 and receives the conjugate phase. This phase assignment does not identify the two L-values at the same positive height.

At t=5h/64 for h=1,2, the shared-phase fixture encloses εχ and G=(q/π)^g Γ(g)q^(−s). Its spectrum encloses Dχ. With M=εχG=A+iB, the exact product MDχ=H is real and M≠0 since Re(g)>0 and Γ has no zeros. Consequently H A=|M|² Re(Dχ) and −H B=|M|² Im(Dχ). A strict enclosure for A and Re(Dχ), or for B and Im(Dχ), gives a sign for H. Signs of disjoint summands in pf−vg or pg+vf can establish the required multiplier coordinate when εχ=p+iv and G=f+ig. Finite exact realness concerns the underlying functions. The rounded product may have a nonzero imaginary coordinate. At reduced precision both the original enclosure radius and the new rounding error enter the strict-coordinate test.

The finite inputs are in sibling directories `c10004-hol-shared-phase` (phase charts and parity factors), `c10004-real-transform` (positive-frequency spectra), and `large-terminal-signs` (coordinate selector). A stock-HOL sign proof for the true function additionally requires the primitive-character identification, Hurwitz sum identity, functional equation and conjugation with this phase, and enclosure theorems for the roots, phase, gamma/conductor factors and Dχ at the queried height. Native Arb data and the cited analytic identities document those premises. This audit supplies no campaign-wide HOL instantiation.
