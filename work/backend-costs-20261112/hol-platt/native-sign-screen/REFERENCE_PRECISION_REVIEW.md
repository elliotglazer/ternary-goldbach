The general path constructs a Hurwitz precomputation using the requested precision plus ceil(log2(phi(c))), calls the contraction, and clears the precomputation for that call. There is no selected approximate-functional-equation path in this dispatcher.

The [Hurwitz contraction](https://raw.githubusercontent.com/flintlib/flint/v3.6.0/src/acb_dirichlet/l_hurwitz.c), lines 42-74, iterates over the unit residues, obtains the corresponding Hurwitz value, multiplies by a character root and sums, then applies c^(-s). For c=10000 that is 4000 terms. The [precomputation initializer](https://raw.githubusercontent.com/flintlib/flint/v3.6.0/src/acb_dirichlet/hurwitz_precomp_init.c), lines 34-74, may allocate an N-by-K coefficient table and fill it with shifted Hurwitz-zeta evaluations. These are its internal N and K, not the spectral pilot's FFT dimensions. The parameter chooser was not retrieved in this review, so no concrete internal dimensions or monotone runtime dependence are asserted.

This explains why the direct API is useful as an independent scalar reference but need not be cheap at high t. In particular, its one-character call does not share the precomputation with the inverse-character call at the same height. That source observation does not identify which internal routine dominates the current pending call.
