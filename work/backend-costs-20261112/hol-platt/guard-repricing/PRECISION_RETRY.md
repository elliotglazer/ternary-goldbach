# When a repair requires another transform

Write \(s=1/2+it\), \(\chi(-1)=(-1)^a\) for \(a\in\{0,1\}\), \(z=(s+a)/2\), \(R=q^sL(s,\chi)\) and \(\eta=\epsilon_\chi^{-1/2}\) in the chosen gauge. The conductor-131071 pilot uses the full factor \(C=e^{\pi t/4}(q/\pi)^z\Gamma(z)q^{-s}\). Its fallback score center divided by \(2^{3p}\) therefore represents \(A_\chi(t)=\Re(\eta C R)\). The separate conductor-10004 p81 shared-phase fixture at low height omits \(e^{\pi t/4}\); its center must be multiplied by that factor after division by \(2^{243}\). The priced dynamic cache supplies \(U=C/|C|=e^{-it\log(q\pi)/2}\Gamma(z)/|\Gamma(z)|\). Its emitted sign codes carry no magnitude. A tap using the full unit-phase coordinates, rather than just the codes, obtains \(X=\Re(\eta U R)\). To recover the un-tilted amplitude used in the derivative theorem, multiply its interval by a certified positive enclosure for

\[
P=|C|=q^{a/2-1/4}\pi^{-a/2-1/4}e^{\pi t/4}|\Gamma(z)|.
\]

The gamma magnitude depends only on parity and height, and the conductor power is static for a given conductor and parity. The phase-cache price does not include this extra magnitude certificate. [Dynamic cache boundaries](../large-dynamic-phases/README.md)

One can interpolate \(A_\chi/q^{a/2-1/4}\) and divide the derivative majorant by the same constant. Then the conductor exponent in that majorant becomes \(b/2+1/4\) for both parities. The remaining table factor is \(H_a(t)=P/q^{a/2-1/4}\). Across all 125,400 conductors at guard +640, the height indices run from 0 to 84,880. Computing both parities for all ticks produces 169,762 entries. A native 128-bit Arb run generated the 16- and 24-bit tables together in 2.20 CPU seconds. The serialized tables occupy 509,286 and 679,048 bytes. The verification run used 4.30 CPU seconds to check every interval using 192-bit direct gamma evaluation and all 84,881 paired products using \(H_0H_1=2/\sqrt{1+e^{-2\pi t}}\). This reflection identity also permits deriving the second table from the first if that tradeoff is separately priced. Relative midpoint error for a \(B\)-bit table is at most \(2^{-B-1}\). The measured native multiplication of a preloaded table entry by a 243-bit center and 179-bit radius took 0.46 microseconds. Formal gamma enclosures, lookups, serialization and kernel admission still need separate verification and timing. **Two-pass acceptance.** For each actual node ball \(c_j\pm d_j\), express both quantities in common physical units, including the scale interval if needed. With exact rational Lagrange weights \(w_j\) the polynomial interval has center \(\sum w_jc_j\) and radius \(D=\sum |w_j|d_j\). Add the strip remainder \(E\). Accept a sign only when its interval excludes zero. A decision to upgrade can be made by any discovery heuristic; sum the actual certified radii again after each upgrade. Inputs of different precisions or algorithms may be mixed if they enclose the identical gauge, height and function. The sign remains unknown until verified. When \(|\sum w_j c_j|+D\le E\), even perfectly precise samples cannot resolve the sign with this particular polynomial and remainder. Shift or extend the stencil, improve the remainder or test the midpoint directly. Multiple requests for the same \((q,j,\chi)\) reuse the same enclosure. For the final Turing count, a missing sign is omitted; an unresolved saturation deficit requires further witnesses or a different completion method.

On the 13 known hidden-reversal cases and two clipped-edge cases at conductor 10,004, a direct p24 integer projection over every actual Hurwitz residue certified all 13 hidden midpoint signs. The two edge intervals stayed ambiguous even after all 16 nodes were raised to p28. A better-positioned stencil resolved them in the separate halo test. Both precisions were checked against all 480 corresponding archived coarse intervals. This is a selected stress set. The tested direct dot-product radius need not equal the packed cyclic transform radius. [Variable-radius results](variable-radius-retry.json) · [Halo test](strip-halo.json)

**Precision costs.** A higher-precision rerun of the entire conductor and height range is unnecessary. A direct sum for a single mode uses that height's complete residue input vector, or an independent direct character evaluator. If suitable residue data are unavailable, the affected conductor-height source panel must be regenerated or replaced. Sparse projection can avoid computing other output modes. For dense requests, a full transform at that height may cost less. The native p48 conductor-131071 retry measured 0.969 versus 2.125 CPU seconds for sparse versus dense low-height corrections, and 2.688 versus 3.000 CPU seconds at the high heights. A per-height hybrid reduced the high total to 2.219 CPU seconds. These are marginal projection costs. Source generation plus rounding added 4.516 CPU seconds on the two touched low heights and 15.875 CPU seconds on the three high heights when regenerated; root, phase and chirp setup were separate.
