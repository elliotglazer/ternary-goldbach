# Two low-height Hurwitz source blocks at conductor 10004

At each of 5/64 and 5/32, all 4,800 complex outputs round uniquely to p81 and agree coordinate by coordinate with the independent direct Hurwitz TSV. Each enclosure includes both Arb arithmetic error and the Taylor remainder. This is a native numerical experiment. The original P20 construction uses a different jet and grid.

For each unit let α=a/10004. The identity ζ(s,α)=α^-s+ζ(s,1+α) separates the singular head. Compute α^-1/2 and exp(−5i log α/64) once per unit. At each sampled height multiply the retained head by this step. The second height consumes the first height's head state. This initialization covers all 4,800 inverse square roots, logarithms and complex exponentials.

Partition [0,1] into 16 equal cells, each with midpoint b=(2j+1)/32. For each midpoint and height compute the 21 coefficients (−1)^k (s)_k ζ(s+k,1+b)/k! at k=0 through 20. The rising factorial ratio is generated by recurrence. Evaluate the polynomial at d=α−b by 20 Horner steps. For s=1/2+it with |t|≤5/32, |s+k|≤k+1 for all k≥0. For k≥2 the absolute Dirichlet series for ζ(s+k,1+b) is bounded by 1+∫₁^∞ x^(-5/2) dx=5/3. The Taylor expansion in d follows by differentiation of Hurwitz zeta; its disk of analyticity extends to the nearest singularity at d=−1−b. Therefore the omitted tail has norm ≤(5/3)(1/32)^21/(1−1/32). Widen each coordinate by this bound before testing strict distance below half a p81 grid spacing.
