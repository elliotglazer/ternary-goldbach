# Band-1 finite EM inputs for the c=10004 mixed-grid replay

At t=5/64, h1-mixed.json gives the 20 signed integer coordinate pairs for each fine anchor k=0 through 1024. Degrees are in ascending order. Their fractional bits are 94,94,94,94,91,89,89,89,83,81,81,81,75,73,73,73,65,65,65,65. The JSON keys are decimal anchor numbers. h1-horner.json contains the 4,800 expected shifted-Hurwitz output rows in tensor order as [index,residue,anchor,real,imaginary], with both output coordinates on grid94. An exact left shift by six exports these centers to grid100. The separate raw finite head belongs to the subsequent assembly.

The generator implements the scaled Euler–Maclaurin source in SCALED_HURWITZ_EM_SEED_PRECISION_2026-11-11.md under work/qrh-campaign/agents/prime-estimates. It uses the 220-term finite head, all 64 Bernoulli corrections, Bernoulli constants computed as exact rationals, rounded complex gates at grid122 and a separate rounded grid122 elementary power for each required base. The elementary powers use 200-bit Arb intervals with strict half-unit conversion checks. This supplies the actual base centers through native interval evaluation. A HOL proof of the elementary powers and the Euler–Maclaurin formula remains outstanding.

For 512 coarse anchors, the source retains 27 coefficients. At the right endpoint it retains 20. All 13,844 grid122 coarse pairs are in h1-coarse-grid122.json. A second computation using the exact normalized derivative formula and Arb Hurwitz zeta checked each coarse error strictly below 2^-102. The largest enclosing norm was below 5.552×10^-35. Even fine anchors reuse the first 20 coarse coefficients. Each of the 512 odd anchors uses the 330-update pruned Pascal loop with normalized displacement 1/2. Each update rounds once to grid110. h1-p20-grid122.json stores all resulting centers in a common grid122 encoding, with exact zero low bits for grid110 results. Each direct conversion into h1-mixed.json reads from these stored centers. Integer nearest rounding takes ties toward positive infinity.

For all units a, the evaluator selected the nearest fine anchor k to 1024a/10004 with ties down, then used the exact displacement 512a/10004−k/2. It performed 19 rounded products and 19 exact additions. Independent 200-bit Arb enclosures of ζ(s,1+a/10004) gave 633 times the local error strictly below 2^-82 for every output. The largest unamplified enclosing norm was below 6.425×10^-29. These successful interval comparisons cover this height. They do not replace a HOL proof of the generic source or transform.
