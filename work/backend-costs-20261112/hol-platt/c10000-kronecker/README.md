# An exact circular convolution for the 500-point Bluestein slice

For even length $n$, write $p_j=\exp(πi j^2/n)$. This chirp is periodic modulo $n$ and $p_kp_j\overline{p}_{k-j}=\exp(2πijk/n)$. Prechirp each rounded input and round the result on grid 307. Convolve it with the rounded conjugate chirp, retaining the exact integer convolution on grid 614. Multiply by the postchirp and round directly back to grid 307. The two 1,024-point Fourier transforms in the earlier convolution implementation are absent from this algorithm. The source, chirps, phase convention and postchirp remain necessary.

Use radix $B=2^{632}$ for the signed complex integer sequences. The largest possible real or imaginary coefficient of the circular product has magnitude at most $2n\max|a_{j,d}|\max|b_{j,d}|$, where $d$ ranges over the two coordinates. The program checks that this bound is below $B/2-1$. Evaluating both polynomials at $B$ and reducing their product modulo $B^n-1$ folds the linear convolution into the desired circular coefficients. Adding a fixed bias to each coefficient before decoding gives unique digits, including for negative results. Three signed integer products suffice for the complex product.

All 500 outputs agreed with an independent integer schoolbook convolution. A separate 448-bit direct Fourier evaluation on the actual conductor-10,000 Gauss slice bounded the maximum error by 57 grid units after terminal rounding. The generic rounded-unit-input bound is 1,769 units. This accuracy check is separate from the proof of correctly packing and multiplying integers. [Independent error calculation](../c10000-kronecker-error/README.md)

Seven native trial medians on the local machine gave 47.28 ms for the full transform using CPython integers and 7.89 ms using FLINT integers with a reusable packed kernel. Three large products alone took 45.73 ms and 2.71 ms respectively. The FLINT path includes conversions to and from its integer type. The earlier cached fixed-grid FFT path used 32.6 ms wall time. The numerical savings depend on the integer engine, and these timings exclude proof admission and export.
