# Shared chirp recurrence

For n even use p_j=exp(πij²/n). For n odd use p_j=(−1)^j exp(πij²/n). Each chirp is periodic modulo n, and p_j p_k conjugate(p_(k−j)) is the correct positive Fourier weight. Let r_0 be exp(πi/n) for even n and its exact negative for odd n. Set z_0=1 and δ=exp(2πi/n). The exact recurrences are z_(j+1)=z_j r_j and r_(j+1)=r_j δ. Only two analytic root enclosures per key are required. The final unused r update can be dropped. The conjugate kernel comes from the same stored centers.

Use q=p+2 ceil(log2(n+1))+6 and g=2^-q. Both analytic seeds and each working-coordinate complex rounding have Euclidean error below g. If e_j bounds ratio error, e_(j+1)≤(1+g)e_j+2g and e_0≤g. Since (1+g)^n≤exp(ng)<2, e_j≤(4j+2)g. For the phase error f_0=0, f_(j+1)≤(1+e_j)f_j+e_j+g. The summed ratio error through n steps is ≤2n²g; hence the product of the amplifications is below exp(2n²g)<2. Therefore f_j≤2(2n²+n)g≤6(n+1)²g≤(6/64)2^-p. The final coordinate rounding adds at most (1/√2)2^-p, and their sum is strictly below 2^-p. The theorem guarantees norm error rather than identity to the exact nearest true root.

At n=500, p307, all 500 integer centers agreed with direct Arb rounding, and the maximum true root error was below 0.693 grid units. At odd n=4093, p100, one complex center differed, with the maximum true error below 0.700. At n=65536, p100, nine differed and all errors were below 0.705. The observed 0.1135 seconds of recurrence wall time at n=65536 excludes independent analytic checking. tests.json records four controls. A production implementation may need increased precision or exact special handling when creating the two guarded analytic seeds.
