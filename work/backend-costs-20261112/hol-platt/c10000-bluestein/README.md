# Conductor-10000 length-500 normalized Bluestein

The input is one actual CRT slice of the conductor's Gauss-sum input. For each j from 0 to 499, r is the unique integer 1<=r<10000 congruent to 1 modulo 16 and 2^j modulo 625. Its complex value is exp(2 pi i r/10000). This is one axis of the small-family phase computation. The saved result comprises the 500 positive-exponent, unnormalized Fourier outputs of that axis.

All runtime products use nearest coordinate rounding on the 2^-307 absolute grid with ties toward positive infinity. Chirps are exp(pi i j^2/500). The padded difference kernel has support j=0 and +/-1,...,+/-499, with conjugate chirps in those slots. A 416-bit native ball FFT computes its positive length-1024 spectrum divided by 1024. Each stored coordinate is accepted only when the whole interval lies strictly in its rounding cell. Thus its complex error is below one grid unit. The same test applies to every pre/post chirp, transform root and input. Each cache row stores the two rounded coordinates and their exact integer sum and difference.

The warm path prechirps the input, uses a positive unnormalized fixed-grid length-1024 FFT, multiplies by the cached normalized kernel, applies a negative unnormalized FFT, and postchirps. This places the entire division by 1024 in the cached kernel. Integer butterfly additions and subtractions are exact. The independent check sums each of the 500 defining positive-transform dot products in 416-bit balls using exact analytic input enclosures. For each output, outputs.tsv gives a rigorous integer upper bound in units of 2^-307 on the absolute distance to its true complex output. The maximum was 704. This covers all runtime, source, chirp and kernel rounding for this instance.

Wall seconds were 0.0065 for input generation, 0.0115 for chirps and roots, 0.0212 for normalized kernel setup including an independent one-slot normalization check, and 0.0326 for applying the in-memory cache. The two runtime FFTs took 0.0142 and 0.0135 seconds. All 250,000 independent direct-DFT terms took 0.374 seconds including output serialization. Cache writes occur outside the setup timings. These native measurements cover one slice and one cache. They do not measure the full Gauss tensor, Gaussian buckets, completion, HOL replay or eviction behavior.
