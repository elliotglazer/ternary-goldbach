# Guarded 128-cell Hurwitz derivative translation

The six +640 bands contain 5,693,448 radius-64 center groups, 84,881 of them final groups. An ordinary group owns integer displacements −64 through +63. Each final group also owns +64. This gives 728,846,225 cell positions and 14,576,924,500 complex output coefficients, including orders 0 through 19.

`fixtures.py` reads `hurwitz-seed-integer/normalized-seeds.json`. At each band's maximum height, it checks the final group at every one of its 129 positions. Every rounded result agrees with `normalize.translated` for both real coordinates at every derivative order. Direct, independently rounded 440-bit FLINT Hurwitz evaluations at −64, 0 and +64 give exactly the same integers in all six cases. The earlier independently generated centers and the actual producer-backed integer fixture have identical bytes (SHA-256 7110150d012bb49f85f393695e364e33c62a62773d8cd54584d40508e1c425f5).

For an input integer coefficient at precision p, center radius r=64, displacement d, Taylor degree D and derivative order k, the integer numerator weights are binomial(m,k) times d^(m−k) times 2^k times r^(D−m). The common grid conversion denominator is 2^(p−94)r^D. Thus a signed term is multiplied by (2/r)^k times (d/r)^(m−k) in the normalized coordinate. The factor 2^k converts to the original cell-derivative variable. The output rounding is floor(x+1/2), including negative values. All included displacements satisfy |d/r|≤1. The original explicit uniform tail and center-seed perturbation bounds give pre-round complex errors of 4.566–8.137 × 10^−6 units of the 94-bit output grid on the six bands. Including per-coordinate final rounding bounds the output complex norm error by 0.707115 grid units, conditional on the seed and analytic coefficient bounds.

`NormalizedTranslate` evaluates both coordinates with a packed 20-lane Horner recurrence and tests all digits of the supplied output word. The kernel replay uses three trials each at 0, 128 and 129 positions with the same complete inputs and reversed trial order. It also checks rejection of a one-unit discrepancy in the last cell's real output word. `norm02_bench.status` is 0.
