# HOL4 source arithmetic and input preparation in all five height bands

HOL4 evaluated the same packed source circuit on real eight-height inputs in each band. Across the five first panels it consumed 27,048, 13,632, 3,840, 344 and 208 complex outputs. Each completed theorem checks a digest of all the outputs against an independent integer calculation. The Python producer enclosed the Taylor coefficients of the shifted Hurwitz zeta function in Arb and rounded them directly onto grid 94. A rational remainder bound, including weight and coordinate rounding, was below 0.323 of the amplified source-error allowance in every sampled interval. Four distinct residues at each height also passed direct Hurwitz interval checks. The HOL measurements begin with the supplied integer coefficients. Their analytic derivation and the later use of their outputs remain separate obligations. At eight heights per block we grouped up to 128 conductors, stopping sooner when the raw output buffer would exceed 837,030,720 bytes. On the selected workload this entails 6.61 billion cell-block calls over all bands, including calls to empty cells. The five panel rates project to about **156,100 core-hours** of source kernel arithmetic, including about **52,700** in the four later bands. One cell per band and one conductor group at that cell supplied the rates. Total proof time can vary with the selected cells, conductor groups and heights. On the first run, charging one measurement of full statement preparation per cell-block call would add about 146,300 hours. A paired HOL4 experiment compared the ordinary and cached encodings on two consecutive, distinct eight-height coefficient arrays in every band. It retained the two theorems encoding the conductors and their residue lists. All sixty evaluations produced the expected answer with the usual kernel audit. On each second height block the cached evaluation reused both theorems and rebuilt the coefficient input. [Paired kernel log](geom01.log) · [Benchmark source](geometry_reuse.py)

Using the medians of three paired preparation timings per second height block gives 102,600 projected hours with ordinary encoding and 12,400 with reuse. Reading the literal coefficients and constructing the associated terms adds about 63,100 hours under the tested layout. Reading the geometry once per change in the set of active conductors adds about 10 hours. Combining these prices with the earlier component estimates gives **734,200–734,750 core-hours at 24 bits** or **764,935–765,465 at 28 bits**, before sign retries, complete counts, coefficient production, short axes, and the rest of the proof. The second set reused the first set's coefficient encoding. At the second interval both sets reused their own residue encodings. All 60 checks passed. Their inputs contain 20 distinct output digests.
