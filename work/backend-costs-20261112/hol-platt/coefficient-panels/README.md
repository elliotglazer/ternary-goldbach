# Producing the shared Hurwitz coefficient tables

The five source bands need 14,367,196,500 complex coefficients on the 94-bit grid if each global table is built once. Evaluating twenty Hurwitz derivatives separately per cell projects to 14,610 native core-hours. With sixteen consecutive cells sharing a Taylor expansion, the measured native proposal cost falls to **2,274 core-hours**. HOL4 then took a projected **2,209 hours** to read and check all the translated groups. The combined 4,483 hours cover native generation and the standalone HOL translation replay. The analytic proofs of the starting values and the formal checks for 84,241 single endpoint cells remain separate. [Native data](panels.json) · [Kernel prices](costs.json)

There are 44,892,224 groups with 2,458,586,688 complex starting coefficients. At group center a₀ and grid parameter f, the degree-m coefficient of ζ(s,a₀ + 2z/f) is (−2/f)^m (s)ₘ ζ(s+m,a₀)/m!. Translating from a₀ to cell offset d adds d/2 to z. Combining the binomial formula with a bound on the absolute Hurwitz series gives a geometric tail bound for every one of the twenty output coefficients. The 320-bit seeds carry sufficient precision for these translations. At four positions in each of fifteen groups, all twenty complex coefficients matched direct Arb evaluation after rounding. [Formulas and checks](panel.py)

The HOL circuit uses Horner evaluation at the integer 2B+d with B = 2^640. The low twenty base-B digits retain the twenty polynomial coefficients. The kernel checks each rounded coordinate after reduction modulo B^20. A seed group returns 640 real coordinates across its sixteen cells. Fifteen independent fresh-input theorems passed, and a one-unit error injected into one expected coefficient produced the required rejection. The fresh group timings include term loading, encoding, evaluation and decoding. Their three band-weighted totals were 1,664, 2,845 and 2,118 hours. The separately measured marginal kernel arithmetic was about 106 hours and is already included in the fresh-input price. For the alternative unit-radius variable, put R equal to half the group width and expand ζ(s,a₀+Ru/f) for |u|≤1. Each output derivative of order k gets an additional factor (2/R)^k. For degree D the absolute error of rounded seeds is amplified by at most binom(D+1,k+1)(2/R)^k. This scaling reduces the required absolute precision of the seeds. Groups of 128 cells need 844,309,768 starting coefficients with 120–122 fractional bits across the five bands. The original 16-cell implementation above remains the one included in the cost model. For the 128-cell variant, a finite Euler–Maclaurin producer reuses each elementary exponential across the Taylor coefficients. The 1,200 sampled complex outputs agreed exactly on the 94-bit grid with direct Hurwitz zeta evaluations. Across the full schedule this producer would use about 8.52 billion phase values, 143.86 billion finite-sum terms and 7.47 billion Euler–Maclaurin correction terms. The native seed generation projects to 64 core-hours at the sampled rates. HOL4 checking of the elementary phases, analytic remainder and translations in the 128-cell layout still needs measurement.
