## Accounting findings

The model preserves the selected combined8828/fullP20/b94 large-family circuit and its +41 guards. It does not credit the later mean186 precision or narrower-runtime-magnitude candidates. Root and nonunit-kernel products remain separate. Normalized runtime division is absent for the stated circuit; cold kernel FFTs, chirps, cache sums and scaled-cache rounding are still charged. The nonchirp root producer is now explicit, but its assumed key counts are not proved to cover the workload. The stress allowance is not a coverage certificate.

Raw residue heads and the finite EM head have different functions and are correctly separate. The source ledger includes EM state updates, reciprocal scales, sums, correction stages, shift updates, copies/conversions, endpoint work and full20 deliveries. Shared coefficient-coordinate conversion is distinct from per-residue Horner work. The Horner bundle must really pay the exact export, lookup, top copy and binding work assigned to it. The current factors are unmeasured complete-role assumptions, so that assignment is a specification for a future benchmark rather than evidence that the work is inexpensive.

The small branch includes character and time transforms, general point products, prefactors, internal scales, conjugate copies, projections and elementary producers. Its ancillary fractional precisions reach 534. A 343-bit rounded rotate-and-pair fixture cannot establish their prices. The model correctly leaves those transfers as assumptions and does not apply a universal Lean/HOL/Candle multiplier.

There is no identified duplicate principal producer charge. The principal row is intended to include search, production, first acceptance, signs and global count work; the separate native generation row excludes it. The 250000001-by4095 layout and complete-role prices remain proposed, not a measured or proved principal algorithm. The nonprincipal closure allowance is distinct from sample arithmetic. It covers count integrals, endpoints, central cases and final binding only by assumption. The original-RH principal requirement does not acquire a new N1500/Q1500 obligation merely because a historical alternate producer used one.

The finite tile price consumes separately established source and anchor prime facts; it is not priced as another proof of their primality. Ladder prices include generation and first acceptance. The dense adaptive ladder has no demonstrated success rate, and its narrower windows cannot inherit the old special-rung timing. The source bitmap, initial interval, exceptions, joins and finite-specific export remain in an uncalibrated reserve. Thus the finite subtotal has all named roles but is not yet a complete production measurement.

## Time, reuse and output boundaries

HOL4 and Candle timing anchors are CPU measurements of checked execution. Lean's 13.464615-second replay anchor is elapsed time treated as busy-core CPU, explicitly a proxy. Its additional frontend allowance is an assumption; it is not obtained by subtracting unrelated import/build totals. The newer Lean batch has slower optional replay but cheaper incremental construction with shared support already built. Neither comparison calibrates a production tile. A first-admission model must not add an optional complete second replay accidentally.

The geometry and retained-refinement factors apply to runtime counts, retained notional blocks and bytes. Failed discovery is assumed to remain in memory and is charged through native-generation retry, rather than producing retained certificates. Other search/output policies can exceed this budget. The notional 8192-operation partition and reuse factors 10000/100/1 are not actual dependency-graph lifetimes. Per-shard imports, cache reloads and serialization remain separate. Persistent reuse must eventually be justified by actual retained definitions, inputs and exact theorem bindings, not hashes.

The runtime payload translation conservatively retains the whole measured fixture even when some coefficients could use the separately admitted cache. This can overlap representation work in an inefficient proposed implementation. The note discloses it and claims no optimum. A future removal needs a matched producer and lifetime proof, not an unexplained refund.

The CPU total includes serialization/root-assembly assumptions. Physical I/O is a separate elapsed-time constraint. The displayed 1000-effective-core figure is only the maximum of CPU-work/1000 and a one-pass bandwidth constraint. It omits critical-path and scalability constraints and is not a calendar forecast. Human engineer-years are separate from CPU; library module/build/rebuild counts are an explicit unmeasured CPU mechanism. Per-shard imported-library loading is not another full source compilation.

## Ordinary PA limitation

The PA calculation is a sensitivity for the measured four-bit scalar proof producer, not a matched signed transform benchmark or an estimate for the best ordinary MM0 implementation. The 0.85-second proposal observation is elapsed time used as a busy-CPU proxy. Frontend production already includes serialization, so there is no second serialization CPU multiplier. The finite ladder is included inside the displayed finite/library/source/closure reserve total and is not added twice.

The width/composition factors and remaining finite/source/library/closure reserves are uncalibrated. They do not establish a translation of complex analysis into ordinary PA or the eventual public theorem. The model correctly makes this route conditional on a suitable analytic foundation and exact assembly. Its enormous finite number does not establish either impossibility or a lower bound.

## What the model can support

The tables can honestly be called end-to-end conditional scenarios for specified proposed implementations. They cannot be described as optimized end-to-end estimates, empirical prediction intervals, a completion upper bound, or measured backend rankings for TG. The stress scenario can still fail if arithmetic precision cannot resolve a sign at the chosen analytic error floor, a count condition fails, a prime path is absent, or a required library/representation bridge is unavailable.

The most useful next evidence remains an actual source-to-sign production block with its complete initialization, coefficients, errors and export. The pinned c10004 row has phi4800, 2301 primitive outputs, axes 2/40/60 and baseline precision81. It contains no Bluestein leaf. It can test actual source assembly and ordered CT, but a different visiting plan is necessary for normalized Blue cache production. This qualification also limits any broader CT/Blue reading of the earlier INDEPENDENT_FEASIBILITY.md recommendation; that frozen report is unchanged.

The closed chi4 sample proves an actual positive-height completed sign under the standard Lean axioms. It does not supply full-family throughput, sign-repair frequency, principal completeness or the missing source/root/cache producers. Likewise, the finite interval pilots establish genuine semantic coverage but do not validate the proposed large tile/rung prices. Those are the actionable uncertainties, rather than an additional universal arithmetic multiplier.

No model correction is requested for this snapshot. Adoption should preserve these qualifications and replace the explicit assumptions only with matched complete measurements or new proved interfaces.
